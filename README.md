# Flexr - Social Media Feed Application

A modern, premium social media application built with Django that allows users to create posts, interact with content, and connect with others in real-time.

## 🚀 Features

-  **User Authentication** - Secure login/register system
-  **Post Creation** - Share text and image posts
-  **Real-time Feed** - Dynamic social media feed
-  **User Profiles** - Customizable user profiles
-  **Likes & Comments** - Interactive engagement features
-  **Responsive Design** - Beautiful UI that works on all devices
-  **Premium Styling** - Animated borders and modern design
